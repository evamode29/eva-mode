# EVA MODE

اسکلت اولیه مستقل فروشگاه اینترنتی EVA MODE.

## فناوری‌ها

- Next.js
- TypeScript
- Tailwind CSS
- ESLint
- App Router

## اجرا

```bash
npm install
npm run dev
```

برای بررسی TypeScript و ساخت production:

```bash
npm run build
```

برای lint:

```bash
npm run lint
```
